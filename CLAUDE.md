ManagerXP is the official company website.

## Project goal
Modern, premium technology company website for ManagerXP.

## UI direction
- Black background
- ManagerXP red accent
- Premium gaming/technology aesthetic
- Clean typography
- Responsive desktop/tablet/mobile
- Professional SaaS presentation

## Rules
- Preserve existing functionality.
- UI changes only unless explicitly requested.
- Do not modify backend/API/database.
- Reuse existing components.
- Do not add dependencies unnecessarily.
- Do not invent company claims, statistics, customers or products.
- Do not replace existing assets without approval.
- Keep accessibility in mind.
- Keep performance in mind.

## When implementing a task
1. Inspect relevant files only.
2. Make the requested changes.
3. Run appropriate checks.
4. Fix errors caused by the changes.
5. Summarize what changed.
